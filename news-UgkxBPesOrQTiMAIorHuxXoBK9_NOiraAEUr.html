Logitech MX Keypad: il centro di controllo IA per sviluppatori

Logitech introduces MX Keypad, a programmable multi-app control centre built to manage AI coding tools, agents and developer workflows.

Logitech ha presentato MX Keypad, il primo centro di controllo IA della serie MX pensato per sviluppatori che lavorano con più applicazioni, agenti e strumenti di programmazione. L’obiettivo è avere prompt, macro e comandi sempre a portata di tasto. ⌨️

MX Keypad è compatibile con strumenti e ambienti di sviluppo come GitHub Copilot, Claude Code, VS Code e IntelliJ IDEA. Ogni tasto è configurabile per controllare una o più app, lanciare comandi, eseguire macro di prompt o intervenire su attività come il refactoring del codice.

Il dispositivo nasce dalla collaborazione con GitHub e include un’integrazione nativa con VS Code e GitHub Copilot. Nella confezione sono compresi anche tre mesi di GitHub Copilot Pro+, riscattabili tramite Logi Options+ sia dai nuovi utenti sia da chi è già abbonato. 💻

Con Logi Actions SDK, sviluppatori e agenti IA possono creare integrazioni personalizzate. Sul Logi Marketplace sono già disponibili plugin per Claude Code e OpenAI Codex, utili per monitorare lo stato degli agenti e controllare strumenti CLI dai tasti fisici.

MX Keypad utilizza plastica riciclata post-consumo certificata e sarà disponibile dall’8 settembre 2026 nei colori Grafite e Grigio Chiaro, al prezzo di 99,99 euro sul sito Logitech e Amazon.
